# 🎬 Movies Metadata Cleaned Dataset (1900–2025)

A comprehensive dataset containing metadata for **946K+ movies** released between 1900 and 2025 🌍 — covering multiple genres, production companies, countries, and financial data (budget, revenue, runtime, popularity, ratings).

---

## 📘 Dataset Overview

| Column | Description |
|---------|-------------|
| `id` | Unique movie ID |
| `title` | Movie title |
| `adult` | Indicates if the movie is for adults only |
| `original_language` | Original language code (ISO 639-1) |
| `origin_country` | Production country code(s) |
| `release_date` | Official release date |
| `genre_names` | List of movie genres |
| `production_company_names` | List of production companies |
| `budget` | Reported movie budget (USD) |
| `revenue` | Total revenue (USD) |
| `runtime` | Movie duration in minutes |
| `popularity` | Popularity score based on TMDB-like metrics |
| `vote_average` | Average user rating |
| `vote_count` | Number of votes received |
